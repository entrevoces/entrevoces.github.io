Run the engine

Local (zero dependencies):

cd services/progression-engine
AUTHOR_TOKEN=dev-author-token PORT=8787 node server.js

Then set Engine URL to http://127.0.0.1:8787 above and Connect. Production port: Cloudflare Workers + D1 (see services/progression-engine/wrangler.toml). Games never hold this token.

Deployment topology (identical game builds; only the engine URL differs)

Local demo        Hub :8000 ┐
                  Games:8001/2 ├─► CPE :8787 (Node)      Console :8003
Judging           GitHub Pages: hub + Concept Clinch
                  Cloudflare Pages: Shift: Consecutive ─► Cloudflare Workers CPE (D1)
New domain        Console ─► CPE (activate DomainConfig) ─► games pick it up on next load

Each game folder under apps/games/ is a complete static site (GitHub Pages / Cloudflare Pages). With the CPE stopped, games show a local-only badge and keep playing; evidence syncs on reconnect with no duplicates.
